# 《出海建站模拟器》需求拆解与可行性分析

> 工作名（暂定）：出海建站模拟器 / Site Builder Tycoon
> 一句话定位：把「独立开发者出海建站」的真实历程做成一个轻量模拟经营 + 事件卡牌游戏，
> 玩家扮演不同背景的角色，经历随机事件与任务，最终达成不同梯度的收入成就（日入 $1 → $10 → $100 → $1000），
> 并生成可分享的「人生结局卡」，上排行榜。核心卖点是 **心路历程的共鸣**，而不是硬核数值。
>
> 灵感来源：《摆摊王逆袭》（叙事+角色+逆袭爽感）、大富翁（回合+机会/命运卡）、
> 财富流（现实财务模拟、"银翅膀"式特殊机会事件）、哥飞社群（日入 X 刀的成就梯度、真实出海故事）。

---

## 0. 结论先行（TL;DR）

**可行，且值得做。** 理由：

1. **技术门槛低**：MVP 是一个纯前端的文字事件卡牌游戏（类似「人生重开模拟器」的玩法骨架 + 数值成长），单页应用即可，排行榜用一个极轻的后端就够。
2. **传播模型清晰**：目标用户（出海/独立开发圈）高度聚集在 Twitter/X、即刻、哥飞社群等地，"结局卡截图分享" 是天然的病毒钩子——这类游戏的获客成本几乎为零。
3. **最大成本不在代码，在内容**：事件文案、角色剧本、数值平衡占 70% 以上工作量。这恰好是"懂出海的人"的优势——事件素材可以直接从社群真实故事里取材，真实感就是护城河。
4. **主要风险**：内容量不足导致 30 分钟玩穿、数值无聊导致"点点点"、以及对真实 IP（哥飞等）的引用需要授权或改编。

建议路线：**2~3 周做一个纯单机、无账号、无后端的 MVP**（约 150~200 张事件卡 + 4 个角色 + 结局分享图），
先在社群里验证"有没有人愿意玩完并截图分享"，验证通过再上排行榜和账号体系。

## 1. 产品定位与目标用户

### 1.1 目标用户

| 人群 | 动机 | 规模/触达 |
|---|---|---|
| 正在做出海建站的独立开发者 | 强共鸣——"这就是我的人生" | 哥飞社群、生财有术、Twitter 中文独立开发圈，高度聚集 |
| 想入坑但没开始的观望者 | 低成本"预演"一遍出海人生，降低认知门槛 | 同上，数量更大 |
| 泛休闲玩家 | 模拟人生类小游戏的猎奇乐趣（参照人生重开模拟器出圈） | 靠传播溢出，不作为设计目标 |

### 1.2 核心体验（设计北极星）

- **心路历程 > 数值成长**。玩家记住的应该是"我熬过了 Google 算法更新那一夜"，而不是"我点了 200 次按钮"。
- 每一局是一段**可叙述的人生**：不同角色 × 随机事件 × 玩家选择 → 不同结局文案。
- 结局必须**值得截图**：一张漂亮的"出海人生总结卡"（角色、关键转折点、最终日收入梯度、称号）。

### 1.3 差异化

| 参照物 | 我们借什么 | 我们不做什么 |
|---|---|---|
| 摆摊王逆袭 | 角色出身差异、逆袭叙事、爽感曲线 | 不做重度放置/氪金数值 |
| 大富翁 | 机会/命运双卡池、回合节奏 | 不做棋盘和多人同屏（MVP 阶段） |
| 财富流 | "银翅膀"式稀有机会事件、现金流思维（被动收入 vs 打工收入） | 不做复杂财务报表 |
| 人生重开模拟器 | 极简交互、快速一局、结局分享 | 不做纯随机——我们要有玩家决策 |

## 2. 玩法核心循环拆解

### 2.1 一局游戏的结构

```
选角色 → 逐周推进（回合制） → 每周：分配精力 + 抽事件卡 + 做任务决策
       → 数值变化（收入/心态/技能/资金） → 达成里程碑或破产/心态崩溃
       → 结局结算 → 生成结局卡 → 分享/上排行榜 → 再来一局（换角色/换流派）
```

- **回合单位**：周（一局约 52~156 回合 = 1~3 年游戏时间，实际游玩 15~30 分钟）。
- **失败条件**：资金耗尽（被迫回去上班-坏结局之一）或心态值归零（放弃/躺平结局）。
- **胜利不是唯一目标**：日入 $0 但"想明白了"的结局也应该是一种有尊严的结局——这是"不同人生体验"的关键。

### 2.2 四维资源（数值骨架）

| 资源 | 含义 | 增 | 减 |
|---|---|---|---|
| 💰 资金 | 生存底线 | 网站收入、兼职、副业事件 | 生活开销（每回合固定扣）、买域名/服务器/工具/投广告 |
| ⚡ 精力 | 每回合行动点 | 每回合恢复；健康事件影响上限 | 做任务消耗；熬夜任务透支（换心态值） |
| 🧠 技能 | 建站/SEO/英语/产品 四个子项 | 做任务、学习事件 | 一般不减，但会"过时"（算法更新事件使 SEO 技能临时贬值） |
| ❤️ 心态 | 心路历程的数值化，本作灵魂 | 正反馈事件（首笔收入、被转发）、休息 | 负反馈事件（被拒、被封、收入归零）、连续无收入回合 |

**关键设计**：收入低谷期心态持续掉 → 玩家必须在"继续死磕"和"休息回血"之间做真实取舍——这就是心路历程的玩法化。

### 2.3 事件系统（对标大富翁机会/命运 + 财富流银翅膀）

三层卡池，按权重和条件触发：

1. **日常事件（~60%）**：小额波动。例：收到第一封用户反馈邮件（+心态）、服务器宕机 2 小时（-心态）、域名续费涨价（-资金）。
2. **命运事件（~30%）**：中等冲击，常带选择。例：
   - Google 核心算法更新：流量 -40%，选择「熬夜分析原因」（-精力+技能）或「摆烂等恢复」（-心态，随机恢复）。
   - AdSense 账号审核被拒 / 封号风波。
   - 大厂发布同类免费产品。
   - 家人质疑："你这一天到晚对着电脑赚了几块钱？"（纯心态事件——共鸣点）。
3. **银翅膀事件（~10%，稀有机会）**：需要满足前置条件才能接住，接住则跃迁。例：
   - 被行业大 V 转发（前置：产品打磨任务完成 ≥3 次），流量 ×5。
   - 某个新需求突然爆发（前置：本回合做过"需求分析"任务），吃到红利期。
   - 收购邀约（前置：月收入 > $500）：卖站落袋为安 vs 继续做大——两条结局线。
   - **设计要点**：银翅膀"没接住"也要明确展示给玩家（"你错过了一次机会，因为你的产品还没准备好"）——遗憾感是心路历程的一部分，也驱动重开。

### 2.4 任务系统（真实建站流程的玩法化）

任务 = 玩家主动消耗精力做的事，直接取材真实工作流，兼具**科普价值**（观望者玩完等于上了一遍出海课）：

- 需求分析 / 关键词调研（提高后续"选品"事件的成功率）
- 上站：买域名、搭站、提交 Google 收录
- 内容与 SEO：写内容、**加外链**（成功率受英语+SEO 技能影响，被拒是常态事件——真实！）
- 发布渠道：Product Hunt / Reddit / Twitter 冷启动
- 变现：挂 AdSense、接入 Stripe、做 Pro 版
- 维护：处理用户反馈、改 bug、防攻击

任务不是清单打卡，而是**流派选择**：SEO 流、社媒流、付费投流、矩阵流（做 10 个小站）——不同角色适配不同流派，构成 replay 价值。

### 2.5 成就梯度与结局（哥飞梯度）

| 里程碑 | 称号（示例） | 设计意图 |
|---|---|---|
| 第一笔收入（$0.01） | 「第一刀最难」 | 全游戏最强正反馈点，配专属演出 |
| 日入 $1 | 「日入一刀，人生分界」 | 圈内梗，天然分享点 |
| 日入 $10 | 「奶茶自由」 | |
| 日入 $100 | 「工资自由」 | 可触发"要不要辞职"剧情（如果角色还在上班） |
| 日入 $1000 | 「传说中的那个人」 | 极难，需要银翅膀 + 流派成型 |
| 特殊结局 | 卖站退休 / 回去上班但收获技能 / 躺平但快乐 / 心态崩溃删库 | 保证"失败"也有叙事价值 |

### 2.6 角色系统（不同人生）

角色 = 初始资源 + 专属事件包 + 专属结局文案。首发 4 个：

| 角色 | 资金 | 精力 | 初始技能 | 专属剧情钩子 |
|---|---|---|---|---|
| 大厂裸辞程序员 | 高（有存款） | 中 | 建站高、英语中 | 存款倒计时焦虑；"前同事升 P8 了"事件 |
| 时间管理宝妈 | 低 | 低但稳定 | 均衡偏低 | 精力碎片化（每回合精力随机）；家庭事件线 |
| 在校学生党 | 极低 | 高 | 英语高、其他低 | 没钱买工具，全靠白嫖额度；考试周精力锁定 |
| 五线小城青年 | 低 | 高 | 全低 | 成长斜率最高（逆袭剧本），信息差事件多 |

角色间体验差异必须**大到值得各玩一遍**，否则角色系统就是皮肤。

### 2.7 排行榜

- 维度：最快达成日入 $100 的回合数、单局最高日收入、生涯总成就。
- 按角色分榜（宝妈榜和程序员榜分开——否则数值强角色垄断，弱角色没人玩）。
- MVP 阶段可以先做**本地成绩 + 结局卡截图**（社群里晒图就是社交排行榜），真排行榜后置。

## 3. 需求维度可行性拆解

### 3.1 技术可行性 ⭐⭐⭐⭐⭐（无风险）

- **MVP = 纯前端单机**：一个 SPA（建议 React/Vue + TypeScript + Tailwind），游戏状态本地 localStorage。事件/任务/角色全部做成 **JSON 数据驱动**（内容与代码分离，后期加卡不改代码）。
- 数值引擎就是一个状态机 + 加权随机抽卡，没有任何技术难点。
- 结局分享图：Canvas/`html-to-image` 前端生成，无需后端。
- **排行榜（二期）**：需要极轻后端（Cloudflare Workers + D1 / Supabase 均可，成本≈0）+ 简单防作弊（提交局内关键事件序列做服务端重放校验，或至少签名校验；文字游戏作弊收益低，够用即可）。
- 多语言：数据驱动天然利于 i18n，但**建议 MVP 只做中文**——梗和心路历程强依赖中文圈语境，英文版是另一款产品。

### 3.2 内容可行性 ⭐⭐⭐（核心工作量，最大瓶颈）

- 估算 MVP 内容量：**150~200 张事件卡 + 30 个任务 + 4 角色 × 各 10 条专属事件 + 15 个结局文案**。
- 一局 15 分钟不重样、玩 3 局不腻，是留存底线。人生重开模拟器的教训：内容消耗速度远超想象。
- **素材来源现成**：哥飞社群、即刻出海圈、Twitter build in public 的真实故事，取之不尽——这是本项目相对"凭空编剧情"的游戏最大的成本优势。
- 缓解手段：事件模板化（同一机制换文案）、上线后开放**社区投稿事件卡**（署名激励，本身又是传播点）。

### 3.3 数值/玩法可行性 ⭐⭐⭐⭐（可控，需迭代）

- 数值复杂度远低于正经模拟经营（单货币主线 + 四资源），Excel/脚本可平衡。
- 最大玩法风险：**中期无聊**（$10 → $100 之间没有新机制）。对策：把银翅膀事件和流派分化集中投放在中期。
- 一局时长必须压在 15~30 分钟：太短没有历程感，太长截图前就流失。

### 3.4 市场/传播可行性 ⭐⭐⭐⭐⭐（本项目最强项）

- 冷启动渠道明确且免费：哥飞社群、即刻、V2EX、Twitter 中文圈——这游戏本身就是给这些人做的"照镜子"产品。
- 传播钩子：结局卡截图（自带称号+人生曲线图）、"你是哪种出海人"的测试属性、排行榜攀比。
- 它本身就是一次 build in public 的绝佳素材：**做这个游戏的过程可以按游戏里的方式发推**，元叙事传播。

### 3.5 商业可行性 ⭐⭐⭐（先不指望，有后手）

- MVP 完全免费（付费墙会杀死传播）。
- 后续可能性：打赏/请喝咖啡、新角色包（¥6 式轻付费）、与出海课程/工具（域名商、Cursor、哥飞星球）的植入合作——游戏里"买域名"事件挂真优惠码，转化路径顺滑且不伤体验。
- 定位建议：先当**获客/品牌资产**看待，不当营收产品看待。

### 3.6 合规与风险 ⭐⭐⭐⭐（注意 IP 引用）

| 风险 | 说明 | 对策 |
|---|---|---|
| 真实人物/社群 IP | "哥飞"、真实大 V 名字直接入游戏有肖像/名誉风险 | 化名致敬（如"飞哥"），或直接联系授权——授权成功反而变成联名传播 |
| 玩法借鉴边界 | 借鉴大富翁/财富流/摆摊王的**机制**（不受版权保护），不抄文案、美术、名称 | "银翅膀"是财富流的特色术语，正式版建议改名（如"风口卡"），文档内部沟通可用 |
| 平台风险 | 若做微信小游戏需版号考量 | MVP 做 **Web 版**规避，小程序后议 |
| 数据合规 | 排行榜若收集昵称/账号 | 匿名昵称即可，不收集个人信息 |

## 4. MVP 范围与里程碑建议

### MVP（目标：2~3 周，验证"有人玩完并分享"）

**做**：
- [ ] 单角色可玩流程跑通（选 1 个角色：大厂裸辞程序员——目标用户自我代入度最高）
- [ ] 四维资源 + 周回合制引擎（JSON 数据驱动）
- [ ] 事件卡 ~100 张（日常/命运/银翅膀三层卡池）+ 任务 ~15 个
- [ ] 成就梯度（第一刀 → $1 → $10 → $100）+ 8 个结局
- [ ] 结局分享卡（前端生成图片）
- [ ] 移动端优先的响应式 Web

**不做**：账号、排行榜后端、多角色、音效动画、i18n、小程序。

**验证指标**：完整玩完率 > 40%；玩完者分享率 > 15%；有人主动投稿事件素材。

### 二期（验证通过后）
- 补齐 4 角色 + 各角色事件线 → 排行榜（分角色榜）→ 社区事件卡投稿 → 流派深化（矩阵流/付费投流）。

### 三期（看数据）
- 赛季制、联名角色（授权 IP）、英文版（重写剧本而非翻译）。

## 5. 开放问题（需要拍板）

1. **游戏名**：出海建站模拟器？一刀人生？Site Builder 逆袭记？——影响域名注册，宜早定。
2. **画风**：纯文字（成本最低、人生重开风）vs 像素风（摆摊王风、更"游戏"但需美术资源）。建议 MVP 纯文字 + 少量 emoji/图标，验证后再上美术。
3. **哥飞梯度/术语引用**：是否去联系授权做成联名？（高收益高确定性，建议争取）
4. **平台**：Web first 已基本确定，但要不要一开始就为小程序留架构余地（影响技术选型：避免依赖小程序不支持的 API）。
