# FableUnion 路线图

愿景：**创作者工具箱** = 内容采集/下载 → 爆款拆解 → 趋势研究 → 原创复刻 → 排版/视频生成 → 自动发布 → 数据复盘

## 阶段 1 — 公众号闭环（当前 MVP）✅

- [x] 公众号文章采集（链接 / 浏览器插件抓取当前页）
- [x] 元数据保存：标题、作者、公众号、封面、发布时间、正文
- [x] 爆款拆解：标题、钩子、结构、案例、金句、转化点
- [x] 原创复刻：同方向新文章生成
- [x] 自动排版（公众号 HTML）
- [x] 发布：公众号草稿 API / Webhook 推送到已有自动发布平台
- [x] Chrome 插件（MV3）

## 阶段 2 — 多平台采集

- [ ] 抖音：视频下载、文案/字幕提取（ASR）、封面与数据
- [ ] 视频号：内容与数据采集
- [ ] YouTube：视频/字幕下载（yt-dlp）、频道分析
- [ ] 小红书、B 站等
- [ ] 统一内容模型：`Content(platform, type=article|video, ...)`（scrapers/base.py 已预留接口）

## 阶段 3 — 趋势研究平台

- [ ] 定时监控指定账号/话题，采集数据快照（阅读/点赞/转发时间序列）
- [ ] 爆款榜单：按领域/平台/时间维度排行
- [ ] 趋势报告：选题热度、标题词频、结构模式统计
- [ ] 选题推荐：基于用户账号定位推荐可复刻的爆款

## 阶段 4 — 视频创作闭环

- [ ] 视频拆解：脚本结构、节奏、钩子、BGM、剪辑手法
- [ ] 脚本复刻生成
- [ ] 接入 Filmgine 视频生成（完成后直接跳转/调用）
- [ ] 视频自动发布（复用现有自动发布平台）

## 阶段 5 — 产品化与商业化

- [ ] 用户系统与多租户
- [ ] 会员付费：免费版（每日限量）/ 专业版（无限拆解+趋势报告）/ 团队版
- [ ] Web 网站正式部署（当前 Web 界面已可直接部署）
- [ ] 数据复盘：发布后效果回收，反哺选题推荐

## 架构演进备注

- 采集层：`scrapers/base.py` 定义了 `Scraper` 接口，新平台只需实现 `match(url)` + `scrape(url)`
- 发布层：`publish/base.py` 定义了 `Publisher` 接口，新渠道只需实现 `publish(article)`
- 拆解/复刻 prompt 与 schema 集中在 `analysis/`，视频拆解可复用同一模式
- 商业化阶段建议把 SQLite 换成 Postgres，任务改为队列异步（拆解/复刻耗时较长）
